# Atlas Perl SDK

`Atlas::Context` reads the version 1 JSON execution context supplied by Atlas.
It uses only Perl core modules and supports Perl 5.20 and newer.

```bash
perl Makefile.PL
make test
make dist
```

Install with the application's selected Perl and local::lib environment using
cpanm or MakeMaker. See `perldoc Atlas::Context` and the repository's operator
reference for environment setup and interpreter compatibility requirements.
