# Atlas Python

Host execution framework and the `atlas_core` Python SDK. Supports Python 3.11–3.14.

```bash
python -m pip install .
python -m pip install -e '.[dev]'
python -m coverage run -m pytest -q
python -m coverage report
python -m build
```

Operator and API documentation: https://github.com/alflag-org/atlas/tree/master/docs
